# PRD v0.2 - NetSage Android

## 用户
- 通信工程学生、实验室助教、小团队网管

## 核心场景
- 用户遇到 DNS、TCP、TLS、HTTP、代理、认证门户或 IP 协议栈异常
- 用户希望在不注册账号、不上传日志的前提下获得可复核的诊断证据

## v0.2 范围
- 输入：粘贴/导入/分享日志，或确认目标地址后执行本地主动探测
- 处理：结构化观察提取 + 版本化本地规则 + DNS/TCP/TLS/HTTP 探测
- 输出：Top 3 诊断假设、匹配/冲突证据、规则优先级与可执行步骤
- 会话：本地历史、修复后复测、Markdown/JSON 导出与系统分享
- 边界：无账号、无自建服务器、无遥测；不做抓包、后台监控或伪装成概率的置信度

## 验证指标
- 合成/脱敏案例的 Top 1 与 Top 3 覆盖率
- 各探测步骤完成时间、超时率和失败类型
- 受控试用中的任务完成时间与建议可执行比例

所有指标必须在实际测试后回填；本 PRD 不预设对外宣传数字。
