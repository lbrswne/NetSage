# PRD v0.2 - NetSage Android

## 用户
- 通信工程学生、实验室助教、小团队网管

## 核心场景
- 用户遇到 DNS、TCP、TLS、HTTP、代理、认证门户或 IP 协议栈异常
- 用户希望在不注册账号、不上传日志的前提下获得可复核的诊断证据

## v0.2 范围
- 输入：粘贴/导入/分享日志，或确认目标地址后执行本地主动探测
- 处理：结构化观察提取 + 版本化本地规则 + DNS/TCP/TLS/HTTP 探测
- TCP：对 DNS 返回的首个 IPv4 与首个 IPv6 地址分别建连；默认各 1 次，可由用户主动选择各 3 次。展示成功/尝试次数与不可用地址族，不推断丢包率；复测保持相同次数。
- 结果详情：仅呈现本机 DNS 探针已保存的 IPv4/IPv6 地址、解析器与可取得的 RCODE/错误信息；复测展示前后 TCP 建连计数，网络变化时阻止直接归因。
- 输出：Top 3 诊断假设、匹配/冲突证据、规则优先级与可执行步骤
- 会话：本地历史、修复后复测、Markdown/JSON 导出与系统分享
- 历史安全：删除单条会话前展示目标，清空全部前展示数量；均提示不可恢复并要求用户再次确认。
- 历史检索：在本机按目标地址或摘要搜索会话，并按体检/组合、日志、复测筛选；不增加网络请求。
- 历史分享：从会话卡片按会话 ID 生成现有 Markdown 报告并调用系统分享面板；不新增报告格式或存储。
- 分享确认：历史卡片与结果页分享完整 Markdown 前，提示可能包含原始日志、网络快照和探测证据；取消不触发系统分享，提示本身不进行脱敏。
- 可选对照：用户确认第二个目标，使用相同协议和端口顺序执行探测；展示两者本次 HTTP 结果。对照结果不参与主目标的规则匹配，也不单独断定根因。
- 边界：无账号、无自建服务器、无遥测；不做抓包、后台监控或伪装成概率的置信度

## 验证指标
- 合成/脱敏案例的 Top 1 与 Top 3 覆盖率
- 各探测步骤完成时间、超时率和失败类型
- 受控试用中的任务完成时间与建议可执行比例

所有指标必须在实际测试后回填；本 PRD 不预设对外宣传数字。
