# Google Play 数据安全表单草稿（v0.2）

> 最终请以实际上线版本行为为准，本草稿用于快速填报参考。

## 是否由开发者收集数据
- 否。日志、网络快照、探测结果和诊断会话默认只保存在用户设备，不发送到 NetSage 或第三方分析服务。

## 本地处理的数据
- 用户主动输入、导入或分享的日志文本
- 当前连接类型、IP、网关、DNS 和主动探测结果
- 本地诊断历史、收藏和导出内容

## 数据用途
- 仅用于设备上的故障诊断、复测比较和报告生成

## 是否共享给第三方
- 应用不会主动共享。用户可自行通过系统分享面板发送导出内容。

## 网络传输说明
- DNS、TCP、TLS、HTTP 探测会连接用户确认的目标地址；目标服务可能按其自身策略记录访问。
- HTTP 模式可能是明文连接，界面会显示协议；HTTPS 模式使用 TLS。

## 删除方式
- 用户可删除单条会话、清空全部本地会话，或通过系统卸载应用清除应用数据。
