# 隐私政策草案（MVP）

我们重视你的隐私。NetSage 无账户、无自建服务器、无遥测和广告 SDK。日志解析、规则诊断、结果与历史记录均在本机处理和保存。

## 我们收集的数据
- 你主动粘贴、导入或分享给 NetSage 的日志文本
- 当前网络的连接类型、IP、网关和 DNS 等诊断快照
- 主动检测产生的 DNS、TCP、TLS 和 HTTP 结果

## 我们如何使用
- 仅用于在本机生成故障分析、排障建议、复测对比和导出文件
- 主动检测会直接连接你确认的目标地址，不经过 NetSage 服务器

## 数据共享
- 不向 NetSage 服务器上传日志或诊断结果
- 不出售个人数据，不包含分析或广告网络请求
- 目标站点会按网络协议接收到正常连接所需的信息；跨主机跳转不会被自动访问

## 数据保存
- 诊断会话默认仅保存在本机，最多保留 20 条；每条原始日志最多保存 100,000 个字符。导入、分享或手动输入超限时会明确提示。
- 用户可删除单条记录或清空全部本地诊断数据
- 文件导入和导出使用 Android 系统文件选择器，不申请广泛存储权限
