# Google Play 上架文案（v0.2 草稿）

## 应用名
NetSage 网诊官

## 一句话简介（80字内）
本地分析网络日志并执行 DNS、TCP、TLS、HTTP 检测，获得可解释的排障建议。

## 详细描述（节选）
NetSage 面向通信工程学习者与网络排障人员。你可以粘贴、导入或分享日志，也可以对自己确认的目标地址执行本地网络检测。应用使用随包规则生成 Top 3 诊断假设，并展示匹配证据、冲突证据和下一步行动。

NetSage 不要求登录，不依赖自建服务器，不上传日志或诊断结果。主动检测只连接你确认的目标地址。规则优先级用于排序，不代表统计概率。

核心能力：
- 日志诊断与组合诊断
- 当前网络快照及 DNS / TCP / TLS / HTTP 检测
- Top 3 可解释诊断假设与修复后复测
- 本地会话及 Markdown / JSON 导出

## 关键词
网络诊断, 故障排查, DNS, TCP, TLS, HTTP, 运维工具, 通信工程
